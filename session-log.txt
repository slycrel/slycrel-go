BACKGROUND
----------
~30 years ago, Dave Dolinar and Jeremy Stone wrote "Slycrel" — a text-based RPG
door game for the Hermes II BBS on Mac Classic, written in Pascal. Dave's older
brother Bill later ported it to C++. The original source code survived across
several moves and decades in a folder called "Legacy Code."

Jeremy decided to bring it back to life.

PHASE 1: FOUNDATION
====================
Built the project skeleton:
  - go mod init github.com/slycrel/slycrel
  - internal/model/ — all data structs translated from SlyHeaders.h
  - internal/io/ — IOProvider interface, ANSI helpers, local terminal with
    raw mode via golang.org/x/term
  - internal/store/ — Store interface, JSON file implementation with atomic
    writes and mutex protection
  - internal/game/ — StateMachine (SetNextState/SetReturnState/PopReturnState
    matching the original exactly), Session, GameEngine
  - cmd/slycrel/main.go — entry point
  - data/ansi/ — placeholder ANSI art screens

First build: clean compile, 3.2MB binary.

PHASE 3: TEXT COMBAT
====================
Read the full Sly_TextCombatUnit.cp and SlyTextCombat.cp to get every formula:

Combat mechanics ported faithfully:
  - RollInitiative: playerMovement - monsterMovement + random(0,3) >= 0
  - DoDamage (user, low level ≤4):
      random(Str*0.75 + Weapon.Strike)*1.25 to (Str/0.75 + Weapon.Strike)*1.35)
      minus Monster.Defense
  - DoDamage (user, high level >4):
      random(Str/2 + Weapon.Strike to same*1.25) minus Monster.Defense
  - DoDamage (monster):
      random(Offense*0.35 to Offense*1.35) minus Player.Armor[0].Defense
  - Monster AI: weighted 50-roll table (50% attack, 10% parry, 14% block,
    14% dodge, 12% run-if-low-HP)
  - 9-state disposition system based on HP percentages
  - Action modifiers: Block=half, Parry=0.6x, Special=1.75x(!!), Dodge=dex check
  - 7 initiative texts for player-first, 3 for monster-first (all from original)

  - Wilderness: Forest/Mountain/Swamp, 15 explorations/day
  - Death: -2% XP, -20% coins, -1 Fame, +1 Faith
  - NewDayForUser: restore psyche, +15 XP, reset explorations/spars

  Created 20 monsters across 3 region JSON files.

PHASES 7+9: ARENA + REMAINING LOCATIONS

  - Win: 10% opponent's spending XP + coins. Loss: dead + opponent gets rewards

PHASE 8: GRID COMBAT
=====================
The crown jewel — the ANSI grid combat system.

Read the full Sly_CombatUnit.cp (1170 lines):
  - 10 terrain types with movement costs (grass=1, forest=2-4, water=998)
  - 12×48 ANSI grid with colored terrain rendering
  - IJKL movement with terrain cost deduction
  - Water = instant death (faithful to original!)
  - Dijkstra pathfinding for monster AI
  - Ranged attacks with distance/dexterity hit chance
  - Stats HUD showing HP, movement, psyche, weapons, armor, monster info
  - Scrolling 5-line combat log
  - Transitions to text combat when player reaches monster

Generated 12 terrain maps: Forest-1/2/3, Mountain-1/2/3, Swamp-1/2/3, Arena-1/2/3
